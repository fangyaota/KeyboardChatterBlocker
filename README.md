# 键盘防抖

机械键盘用久了会出现**按一次却触发多次**的毛病（抖动 / chatter）。这个工具把多出来的那几次掐掉。

每个键可以单独设阈值 —— 坏键被压住，其余的键照常灵敏。

**Windows 10/11** · 需要 [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0) · [下载最新版](https://github.com/fangyaota/KeyboardChatterBlocker/releases/latest)

本仓库是 [FreneticLLC/KeyboardChatterBlocker](https://github.com/FreneticLLC/KeyboardChatterBlocker) 的中文界面重写版：界面全部重写，拦截逻辑沿用原版。

## 怎么用

1. 「按键配置」页把你怀疑有问题的键加进来，阈值先填 `300` 毫秒
2. 正常打字，在「抖动日志」页看实际拦下了什么、每次的「抖动间隔」是多少
3. 按观察到的最大值往下调，调到打字不再被误拦为止
4. 左侧「全局抖动阈值」设一个值，覆盖其余没单独配的键（也可以留在 `0`）

> 阈值单位是毫秒：同一个键两次按下的间隔小于它，后一次就被当成抖动丢掉。`0` = 不拦。

左侧的「启用」开关一开就全局生效。**调试时先别开** —— 程序装的是全局键盘钩子，会拦下你用来改配置的那些按键。用「键盘测试」页看更安全。

## 页面

| 页面 | 干什么 |
|---|---|
| 抖动日志 | 每拦下一次记一条：时间、哪把键盘、哪个键、间隔多少、当时的阈值 |
| 统计 | 各键的按下次数、抖动次数、抖动率 |
| 按键配置 | 逐键设阈值 |
| 键盘测试 | 整张 104 键盘实时高亮：**蓝 = 放行，红 = 被拦**。被拦过的键松手后仍留一圈红框，测完一眼就能看出哪些键有问题 |
| 键盘设备 | 选择在哪些键盘上生效（默认全部） |
| 自动禁用程序 | 列表里的程序在前台时自动暂停拦截 |
| 其他设置 | 计时起点、排除注入事件、长按救援阈值等杂项，一般保持默认 |
| 关于 | 版本信息 |

右侧常驻一条读数边栏，显示最近按的键和间隔、当前按住的键。标题栏右侧的面板图标按钮可以收起它。

## 只在某一把键盘上生效

多键盘的时候，可能只想拦坏了的那把。

- 「键盘设备」页勾选要拦的键盘，没勾的不受影响。分不清哪把是哪把就点「识别」，再按一下那个键盘，对应的行会亮。
- 「抖动日志」「统计」「按键配置」「键盘测试」四页右上角都有键盘筛选框。在「按键配置」页选了某把键盘，就是在给那把键盘设**专属**阈值：

```ini
key.H: 100              # 所有键盘上 H 键的阈值
key.1a2c-7fff.H: 60     # 只在短 id 为 1a2c-7fff 的那把键盘上改成 60
```

## 长按救援（默认关闭）

判定抖动的代价是：被丢掉的那次按下**根本不会进入系统**。按住不放的键（比如方向键）如果按得够快，也会被误伤，而且游戏在整个长按期间都收不到它。

打开后，被拦下的按键只要继续按住超过设定时长，程序会补发一次按下把它救回来。在「其他设置」页调阈值，`0` 为关闭。

默认关着是因为：这是程序里唯一会主动往输入流写数据的地方，个别游戏（尤其带反作弊的）会丢弃合成事件。

## 配置文件

`config.txt` 放在 exe 旁边；exe 装在 `Program Files` 下则改放 `%localappdata%\KeyboardChatterBlocker\config.txt`。统计写在 `blocker_stats.csv`。

格式与原版一致，可以直接沿用旧配置：

```ini
is_enabled: false
global_chatter: 100
key.H: 120
key.E: 60
hotkey_toggle: ctrl + alt + shift + F9
```

## 已知限制

- **仅 Windows。** 依赖低级键鼠钩子，登录界面等受保护区域覆盖不到。
- 少数反作弊系统可能把它误判成可疑程序。
- 与部分越南语输入法（EVKey、Unikey）冲突 —— 它们会发特殊键码。
- 装在内核态读 HID 的反作弊游戏拦不住（输入压根不经过用户态钩子）。
- 窗口的 DPI 缩放只在启动时确定，运行中拖到缩放比例不同的显示器不会重新排版。
- 为了识别键盘，程序会常驻一个**无窗口的同名进程**，跟着主进程一起退出。
- 刚换键盘之后的第一次按键可能被算到上一把键盘头上，按第二下就纠正了。
- 「抖动日志」「统计」等只用来读的页面**故意不接受键盘焦点** —— 这是键盘工具，空格和方向键得留给下面的东西。鼠标点击、滚轮、双击都照常。
